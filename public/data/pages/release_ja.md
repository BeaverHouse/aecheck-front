# リリースノート

大事な変更だけをここに記録します。2026年11月から記録しています。

## 2026-11-28

### スクリーンショットでチェック

- ゲームのメニュー → 記録 → スタイル画面のスクリーンショットをアップロードすると、所持キャラクターを見つけてチェックします。複数枚をまとめてアップロードできます。
- チェックする前に見つかったキャラクターを表示するので、外したいキャラクターはタップで外せます。
- ★4と★5は同じ絵なので区別できません。★4を選んでおくので、★5を持っている場合は切り替えてください。
- 似た絵があって確実でないキャラクターと、AE Checkにないキャラクターは分けて表示します。
- 画像が端末の外に送信されることはありません。照合はブラウザの中だけで行います。
- 初回はキャラクター画像のダウンロードに10秒以上かかることがあります。

### チェック画面

- スマートフォンでリストの上に並んでいたボタンの行を減らしました。
- フィルターごとに何を絞り込むかの名前が付き、タップすると項目を選べます。
- グラスタの段階はグラスタなし / グラスタ装着 / 真グラスタ装着、星導覚醒は覚醒ゲージ 0/3〜2/3 / 覚醒済みと表示します。
- すべてチェック・すべて解除のような一括操作は ⋯ メニューにあります。
- ページ送りをリストの下に移しました。
- お知らせを閉じても再び表示される問題を修正しました。
