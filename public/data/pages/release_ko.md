# 릴리스 노트

중요한 변경만 모아 여기에 적어요. 2026년 11월부터 기록해요.

## 2026-11-28

### 스크린샷으로 체크

- 게임의 메뉴 → 기록 → 스타일 화면을 캡처해서 올리면 보유한 캐릭터를 찾아 체크해요. 여러 장을 한 번에 올릴 수 있어요.
- 체크하기 전에 찾은 캐릭터를 보여 드리고, 빼고 싶은 캐릭터는 오른쪽 위 − 버튼을 눌러 뺄 수 있어요.
- 노말 스타일은 4성 이미지로 대표 이미지를 설정할 수 있어 구분할 수 없어요. 따로 분류되니 직접 바꿔 주세요.
- 비슷한 그림이 있어 확실하지 않은 캐릭터와 ★3 동료처럼 AE Check에 없는 캐릭터는 따로 보여 드려요.
- 이미지는 서버로 전송되지 않아요.
- 10~20초 정도까지 시간이 걸릴 수 있어요.

### 체크 화면

- 필터 UI를 개선하고 모바일 최적화를 진행했어요.
- 전체 체크·해제처럼 한꺼번에 바꾸는 기능은 ⋯ 메뉴로 옮겨졌어요.
- 페이지 넘김이 목록 아래로 옮겨졌어요.
- 공지를 닫아도 다시 보이던 문제를 고쳤어요.
