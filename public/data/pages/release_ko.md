# 릴리스 노트

중요한 변경만 모아 여기에 적어요. 2026년 11월부터 기록해요.

## 2026-11-28

### 스크린샷으로 체크

- 게임의 메뉴 → 기록 → 스타일 화면을 캡처해서 올리면 보유한 캐릭터를 찾아 체크해요. 여러 장을 한 번에 올릴 수 있어요.
- 체크하기 전에 찾은 캐릭터를 보여 드리고, 빼고 싶은 캐릭터는 눌러서 뺄 수 있어요.
- ★4와 ★5는 그림이 같아서 구분할 수 없어요. ★4로 골라 두니, ★5를 가지고 있다면 직접 바꿔 주세요.
- 비슷한 그림이 있어 확실하지 않은 캐릭터와 AE Check에 없는 캐릭터는 따로 보여 드려요.
- 이미지는 기기 밖으로 나가지 않아요. 비교는 브라우저 안에서만 해요.
- 처음 쓸 때는 캐릭터 그림을 내려받느라 10초 넘게 걸릴 수 있어요.

### 체크 화면

- 휴대폰에서 목록 위에 쌓이던 버튼 줄을 줄였어요.
- 필터마다 무엇을 거르는지 이름이 붙었고, 누르면 항목을 골라요.
- 글래스터 단계는 글래스터 없음 / 글래스터 장착 / 진 글래스터 장착으로, 성도각성은 각성 게이지 0/3 ~ 2/3 / 각성 완료로 보여요.
- 전체 체크·해제처럼 한꺼번에 바꾸는 기능은 ⋯ 메뉴에 있어요.
- 페이지 넘김이 목록 아래로 옮겨졌어요.
- 공지를 닫아도 다시 보이던 문제를 고쳤어요.
